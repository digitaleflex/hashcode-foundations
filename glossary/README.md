# Glossaire commun

Ce dossier contient les termes réutilisés dans plusieurs modules. Les définitions doivent être courtes, exactes et adaptées aux débutants.

## Modèle de définition

- **Terme français (terme anglais)** : définition en une ou deux phrases.
- **Exemple** : situation concrète qui aide à comprendre le terme.
- **À ne pas confondre avec** : autre terme proche, lorsque nécessaire.
- **Modules associés** : liens vers les chapitres pertinents.

## Premiers termes à documenter

CPU, RAM, stockage, système d'exploitation, processus, permission, adresse IP, LAN, routeur, port réseau, TCP, UDP, client-serveur, DNS, domaine, HTTP, HTTPS, TLS, authentification, authentification multifacteur, vulnérabilité, menace, risque, phishing, logiciel malveillant et sauvegarde.

Éviter de maintenir plusieurs définitions contradictoires d'un même terme dans les modules : utiliser le glossaire commun comme référence et ajouter des précisions contextuelles dans les cours si nécessaire.
