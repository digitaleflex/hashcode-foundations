# Ressources complémentaires

Ce dossier référence des ressources externes vérifiées et utiles pour les apprenants.

## Critères de sélection

- Source officielle, universitaire ou techniquement reconnue en priorité.
- Ressource accessible, stable et adaptée au niveau visé.
- Indiquer le titre, l'organisme ou l'auteur, le lien, la langue, le niveau et la date de consultation.
- Distinguer documentation de référence, tutoriel et opinion.
- Vérifier périodiquement les liens et les pages dont le contenu change.

## Fiche recommandée

```text
Titre :
Organisme / auteur :
Lien :
Langue :
Niveau :
Modules associés :
Date de vérification : YYYY-MM-DD
Pourquoi cette ressource :
```

Ne pas transformer ce dossier en catalogue de liens non commentés : chaque ressource doit avoir une raison pédagogique claire.
