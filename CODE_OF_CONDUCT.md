# Code de conduite

HashCode Foundations doit rester un espace d'apprentissage respectueux, inclusif et constructif.

- Traiter les autres avec respect, quel que soit leur niveau technique.
- Donner des retours précis, utiles et orientés vers l'amélioration.
- Accueillir les questions de débutants sans moquerie ni humiliation.
- Ne pas publier de données personnelles, secrets, identifiants ou contenu obtenu sans autorisation.
- Signaler les comportements abusifs aux responsables du dépôt.

Les responsables du projet peuvent modérer les contributions qui enfreignent ces principes.
