# Module 05 — Premières commandes système

## Objectifs

À la fin du module, l'apprenant doit pouvoir ouvrir un terminal, identifier le répertoire courant, lister son contenu, changer de répertoire et afficher des informations système élémentaires.

## Principes

- Expliquer ce que chaque commande fait avant de l'exécuter.
- Utiliser un répertoire de test et des fichiers fictifs.
- Éviter les commandes destructrices ou nécessitant des privilèges élevés.
- Présenter séparément les variantes Windows PowerShell et Linux lorsque nécessaire.

## Notions à traiter

1. Terminal, shell et invite de commande
2. Répertoire courant et chemins
3. Lister et parcourir des fichiers
4. Afficher des informations système simples
5. Lire l'aide et comprendre les erreurs

## Exercices

Créer une arborescence de test, se déplacer entre ses dossiers, lister les fichiers et expliquer chaque commande utilisée.

## Critère de réussite

L'apprenant peut effectuer une courte séquence de navigation sans copier aveuglément une commande et sait reconnaître quand il doit demander une explication.
