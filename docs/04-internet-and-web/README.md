# Module 04 — Internet et Web

## Objectifs

À la fin du module, l'apprenant doit pouvoir :

- distinguer Internet et le Web ;
- expliquer le rôle du DNS ;
- décrire une requête Web à haut niveau ;
- distinguer HTTP et HTTPS ;
- expliquer le rôle général de TLS et d'un certificat.

## Notions à traiter

1. Internet et Web : concepts distincts
2. Domaines et DNS
3. Navigateur, client et serveur Web
4. Requêtes et réponses HTTP
5. HTTPS, TLS et certificats
6. Limites de ce que HTTPS garantit

## Critère de réussite

L'apprenant peut raconter les grandes étapes entre la saisie d'un nom de domaine et l'affichage d'une page Web, sans devoir détailler les algorithmes cryptographiques.

## Précision importante

HTTPS protège les échanges en transit selon les propriétés de TLS, mais ne rend pas automatiquement un site digne de confiance et ne garantit pas qu'il soit exempt de contenu malveillant.
