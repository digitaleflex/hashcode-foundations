title: Quiz de positionnement
description: 12 questions pour repérer les notions à réviser avant la cybersécurité.
---

Ce quiz est **diagnostique et non éliminatoire**. Réponds sans consulter les cours, puis vérifie tes réponses dans le corrigé. Le but est d’identifier les thèmes à réviser, pas de juger ton potentiel.

## Questions

### 1. Quel composant conserve généralement les données après l’arrêt de l’ordinateur ?

- A. La RAM
- B. Le SSD ou le disque dur
- C. Le processeur
- D. Le ventilateur

### 2. Quel est le rôle principal d’un système d’exploitation ?

- A. Gérer les ressources et permettre l’exécution des applications
- B. Fournir obligatoirement Internet
- C. Remplacer tous les logiciels
- D. Empêcher toutes les attaques

### 3. Qu’est-ce qu’une adresse IP ?

- A. Un mot de passe
- B. Une adresse utilisée pour communiquer au niveau IP
- C. Un nom de fichier
- D. Un antivirus

### 4. Quel est le rôle principal d’un routeur ?

- A. Acheminer des paquets entre des réseaux
- B. Stocker tous les mots de passe
- C. Remplacer le système d’exploitation
- D. Chiffrer automatiquement tous les fichiers

### 5. À quoi sert principalement le DNS ?

- A. À retrouver des informations associées à un nom de domaine
- B. À créer des sauvegardes
- C. À supprimer les virus
- D. À accélérer le processeur

### 6. Que signifie généralement HTTPS pour une connexion Web ?

- A. Les échanges sont protégés par TLS lorsque la connexion est correctement établie
- B. Le site est nécessairement honnête
- C. Le site ne peut pas être compromis
- D. L’utilisateur est anonyme

### 7. Pourquoi utiliser un compte standard au quotidien ?

- A. Pour limiter les privilèges disponibles
- B. Pour rendre toujours l’ordinateur plus rapide
- C. Pour éviter les mises à jour
- D. Pour désactiver les journaux

### 8. Un message inattendu demande ton mot de passe via un lien urgent. Quel est le meilleur réflexe ?

- A. Cliquer rapidement
- B. Répondre avec le mot de passe
- C. Ignorer le lien et vérifier par un canal officiel
- D. Transférer le message à tout le monde

### 9. À quoi sert l’authentification multifacteur (MFA) ?

- A. À ajouter une preuve d’identité supplémentaire
- B. À remplacer les sauvegardes
- C. À augmenter le stockage
- D. À cacher systématiquement l’adresse IP

### 10. Pourquoi effectuer des sauvegardes régulières ?

- A. Pour faciliter la récupération après une perte ou un incident
- B. Pour empêcher tous les courriels indésirables
- C. Pour garantir qu’aucun fichier ne sera infecté
- D. Pour remplacer les mises à jour

### 11. Que décrit le mieux un port réseau ?

- A. Une valeur qui aide à identifier un service de communication sur un hôte
- B. Le numéro de série d’un ordinateur
- C. Une adresse postale
- D. Un dossier

### 12. Peut-on scanner un réseau tiers sans autorisation pour s’entraîner ?

- A. Oui, si aucun résultat n’est enregistré
- B. Oui, si l’outil est gratuit
- C. Non, les tests doivent être autorisés
- D. Oui, sous Linux

## Corrigé

<details>
<summary>Afficher les réponses et les explications</summary>

1. **B** — Le stockage persistant conserve les données sans alimentation.
2. **A** — Le système d’exploitation gère les ressources, les fichiers, les utilisateurs et les processus.
3. **B** — Une interface réseau utilise une adresse IP pour communiquer au niveau IP ; cette adresse peut changer.
4. **A** — Le routeur transfère les paquets entre réseaux selon les routes disponibles.
5. **A** — Le DNS permet notamment la résolution des noms de domaine.
6. **A** — HTTPS protège le transport, mais ne prouve pas qu’un site soit bienveillant.
7. **A** — Le moindre privilège limite les actions possibles en cas d’erreur ou de compromission.
8. **C** — Une vérification indépendante réduit le risque d’hameçonnage.
9. **A** — Le MFA combine plusieurs facteurs d’authentification selon le mécanisme.
10. **A** — Les sauvegardes facilitent la récupération et doivent être protégées et testées.
11. **A** — Les ports distinguent des destinations de communication sur un hôte.
12. **C** — Les tests doivent rester sur ses propres systèmes ou dans un cadre explicitement autorisé.

</details>

## Interpréter le résultat

Compte tes réponses correctes :

- **0 à 4 :** commence par les bases informatiques et le vocabulaire.
- **5 à 8 :** suis le parcours standard et révise les domaines manquants.
- **9 à 12 :** vérifie tes acquis avec quelques exercices pratiques avant d’accélérer.

Ces seuils sont indicatifs. Une bonne réponse à un QCM ne prouve pas à elle seule une compétence pratique.
