## Comment utiliser ce site

1. Passe le [quiz de positionnement](/evaluation/quiz-positionnement/) pour repérer les notions que tu connais déjà.
2. Suis les modules dans l’ordre conseillé, ou révise les sujets qui te manquent.
3. Réalise les exercices dans un environnement personnel ou autorisé.
4. Explique les concepts avec tes propres mots avant de passer aux fondamentaux de la cybersécurité.

> **Principe HashCode :** l’objectif n’est pas de mémoriser des termes, mais de comprendre comment les systèmes fonctionnent et pourquoi cela compte pour leur sécurité.
