---
title: "Atelier 01 · Explorer son ordinateur"
description: Un exercice guidé pour identifier les composants et organiser des fichiers.
---

## Objectif

Relier le vocabulaire du module 01 à des observations sur un ordinateur personnel.

**Durée :** 20 minutes.  
**Matériel :** un ordinateur auquel tu es autorisé à accéder.  
**Risque :** faible ; aucune modification système n'est nécessaire.

## Consignes

1. Note le nom du système d’exploitation et sa version.
2. Repère la quantité de mémoire vive disponible.
3. Repère le type et la capacité du stockage si les informations sont accessibles.
4. Crée un dossier nommé HashCode-Lab, puis un sous-dossier Notes.
5. Crée un fichier texte nommé observation.txt.
6. Relève le chemin du fichier.
7. Explique en quelques phrases la différence entre CPU, RAM et stockage.

## Tableau à compléter

| Élément | Observation | Ce que cela signifie |
| --- | --- | --- |
| Système d’exploitation | À compléter | Quel logiciel de base gère la machine ? |
| Mémoire vive | À compléter | Quelle quantité de données actives peut-elle accueillir ? |
| Stockage | À compléter | Où les fichiers sont-ils conservés durablement ? |
| Chemin du fichier | À compléter | Où se trouve le fichier créé ? |

## Questions de réflexion

1. Pourquoi le fichier reste-t-il sur le stockage après la fermeture de l’éditeur de texte ?
2. Quelles ressources l’éditeur utilise-t-il lorsqu’il est ouvert ?
3. Quelles informations présentes dans une capture d’écran devraient être masquées avant de la partager ?

## Critères de réussite

- Les quatre observations sont renseignées.
- Le chemin du fichier est exact.
- L’explication distingue clairement mémoire temporaire et stockage persistant.
- Aucune information sensible n’est publiée.

## Corrigé indicatif

Le CPU exécute les instructions, la RAM conserve temporairement les données actives et le stockage conserve les fichiers durablement. L’éditeur de texte utilise le CPU et la RAM pendant son exécution, tandis que le fichier est enregistré sur le stockage. Le nom du compte utilisateur, les identifiants, les clés de licence et les chemins personnels peuvent devoir être masqués avant partage.
