## Objectif

Construire un modèle simple d’un réseau et expliquer le rôle de ses composants sans scanner ni modifier le réseau réel.

**Durée :** 25 minutes.  
**Matériel :** papier ou outil de dessin.

## Scénario

Une personne utilise un ordinateur portable connecté en Wi-Fi à un routeur domestique. Elle ouvre un site Web hébergé sur un serveur distant.

## Consignes

1. Dessine l’ordinateur, le routeur, Internet et le serveur Web.
2. Trace une flèche de la requête et une flèche de la réponse.
3. Ajoute une légende pour l’adresse IP, le port et le protocole.
4. Explique le rôle du routeur.
5. Explique pourquoi l’adresse IP et le port répondent à des questions différentes.
6. Ajoute une note indiquant qu’un appareil peut avoir plusieurs interfaces réseau.

## Questions de réflexion

1. Le routeur domestique est-il nécessairement le serveur Web demandé ?
2. Pourquoi le navigateur et le serveur jouent-ils des rôles différents dans cet échange ?
3. Une adresse IP identifie-t-elle toujours la même personne ou le même appareil ?

## Critères de réussite

- Les composants et les flèches sont correctement nommés.
- Adresse IP, port et protocole ne sont pas confondus.
- Le rôle du routeur est expliqué avec des mots simples.

## Corrigé indicatif

Le routeur transfère des paquets entre réseaux. Le navigateur est le client qui initie la demande ; le serveur Web fournit la ressource. L’adresse IP aide à acheminer les paquets vers une interface, tandis que le port identifie une destination de transport sur l’hôte. Les adresses peuvent changer ou être partagées : elles ne constituent pas une identité personnelle permanente.
