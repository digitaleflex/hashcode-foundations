# Quiz de positionnement — Préparation à la cybersécurité

> Quiz diagnostique : il sert à personnaliser le parcours, pas à exclure les débutants. Répondre sans chercher les réponses permet d'identifier les notions à réviser.

## Questions

### 1. Quel composant conserve généralement les données même après l'arrêt de l'ordinateur ?
- A. La RAM
- B. Le SSD ou le disque dur
- C. Le processeur
- D. Le ventilateur

### 2. Quel est le rôle principal d'un système d'exploitation ?
- A. Gérer les ressources de l'ordinateur et permettre l'exécution des applications
- B. Fournir obligatoirement une connexion Internet
- C. Remplacer tous les logiciels
- D. Empêcher toutes les attaques

### 3. Qu'est-ce qu'une adresse IP ?
- A. Un mot de passe
- B. Une adresse utilisée pour identifier une interface sur un réseau IP
- C. Un nom de fichier
- D. Un type d'antivirus

### 4. Quel est le rôle principal d'un routeur ?
- A. Acheminer des paquets entre des réseaux
- B. Stocker les mots de passe de tous les utilisateurs
- C. Remplacer le système d'exploitation
- D. Chiffrer automatiquement tous les fichiers

### 5. À quoi sert principalement le DNS ?
- A. À associer des noms de domaine à des informations comme des adresses IP
- B. À créer des copies de sauvegarde
- C. À supprimer les virus
- D. À accélérer le processeur

### 6. Que signifie généralement HTTPS pour une connexion Web ?
- A. Les échanges sont protégés par TLS, sous réserve d'une connexion correctement établie
- B. Le site est nécessairement honnête
- C. Le site ne peut pas être compromis
- D. L'utilisateur est anonyme sur Internet

### 7. Pourquoi utiliser un compte standard pour les tâches quotidiennes ?
- A. Pour réduire les privilèges disponibles et limiter certains impacts
- B. Pour rendre l'ordinateur plus rapide dans tous les cas
- C. Pour éviter toutes les mises à jour
- D. Pour désactiver les journaux système

### 8. Tu reçois un message urgent demandant ton mot de passe via un lien inattendu. Quel est le meilleur premier réflexe ?
- A. Cliquer rapidement avant l'expiration
- B. Répondre avec son mot de passe
- C. Ne pas utiliser le lien et vérifier la demande par un canal officiel
- D. Transférer le message à tous ses contacts

### 9. À quoi sert l'authentification multifacteur (MFA) ?
- A. À ajouter une preuve d'identité en plus du mot de passe ou d'un autre facteur
- B. À remplacer systématiquement les sauvegardes
- C. À augmenter la capacité de stockage
- D. À cacher l'adresse IP dans tous les cas

### 10. Pourquoi effectuer des sauvegardes régulières ?
- A. Pour faciliter la récupération des données après une perte ou un incident
- B. Pour empêcher tous les courriels indésirables
- C. Pour garantir qu'aucun fichier ne sera jamais infecté
- D. Pour remplacer les mises à jour de sécurité

### 11. Quelle proposition décrit le mieux un port réseau ?
- A. Une valeur qui aide à identifier un service ou une application de communication sur un hôte
- B. Le numéro de série d'un ordinateur
- C. Une adresse postale
- D. Un dossier du système

### 12. Est-il acceptable de scanner un réseau tiers sans permission pour s'entraîner ?
- A. Oui, si l'on n'enregistre aucun résultat
- B. Oui, si l'outil est gratuit
- C. Non, les essais doivent être autorisés et limités à un environnement approprié
- D. Oui, tant que l'on utilise Linux

## Corrigé commenté

1. **B** — Le stockage persistant conserve les données sans alimentation, contrairement à la RAM classique.
2. **A** — Le système d'exploitation gère notamment les ressources matérielles, les fichiers, les utilisateurs et les processus.
3. **B** — Une interface réseau utilise une adresse IP pour communiquer au niveau IP ; ce n'est pas nécessairement un identifiant permanent de la machine.
4. **A** — Le routeur transfère les paquets entre réseaux selon les routes disponibles.
5. **A** — Le DNS fournit notamment la résolution des noms de domaine.
6. **A** — HTTPS protège le transport entre le client et le serveur, mais ne garantit pas que le site soit bienveillant.
7. **A** — Le principe du moindre privilège réduit les possibilités d'action et certains impacts en cas d'erreur ou de compromission.
8. **C** — Vérifier la demande indépendamment du lien reçu aide à éviter l'hameçonnage.
9. **A** — Le MFA combine des facteurs de catégories différentes, selon le mécanisme utilisé.
10. **A** — Une sauvegarde exploitable contribue à la récupération ; elle doit être protégée et testée.
11. **A** — Les ports permettent de distinguer des destinations de communication sur un hôte, en complément des adresses IP.
12. **C** — Les tests doivent être réalisés sur ses propres systèmes ou dans un cadre explicitement autorisé.

## Interprétation indicative

- **0–4 bonnes réponses** : commencer par les bases informatiques et reprendre le vocabulaire progressivement.
- **5–8 bonnes réponses** : suivre le parcours standard et réviser les domaines manquants.
- **9–12 bonnes réponses** : vérifier les acquis par une démonstration ou un exercice pratique avant d'accélérer.

Ce seuil est indicatif. Examiner les réponses par thème et demander à l'apprenant d'expliquer son raisonnement est plus utile que de s'appuyer uniquement sur le score global.
